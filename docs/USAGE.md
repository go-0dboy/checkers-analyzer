# Инструкция пользователя

## Запуск
Откройте приложение через локальный сервер или GitHub Pages (см. `DEPLOY.md`).
Двойной клик по `index.html` не подходит — ES‑модулям нужен http(s).

## Интерфейс анализа
Слева — доска с плашками игроков сверху и снизу и панелью управления под доской;
справа — афиша метаданных и дерево нотации.

- **Плашка игрока** светится золотом, когда ему ходить; пульсирующий красный
  бейдж «взятие» означает обязательное взятие; по окончании партии победитель
  получает бейдж «Победа», при ничьей обе стороны — «Ничья». Лоток справа от
  имени показывает съеденные фигуры.
- **Панель управления:** новая партия (с подтверждением, если есть ходы) ·
  навигация ⏮  ▶ ⏞ · переворот доски · комментарий к текущему ходу.

## Ходы
- Клик по своей фигуре подсвечивает доступные ходы (зелёные точки — тихие,
  красные кольца — взятия). Клик по подсветке — ход.
- Перетаскивание фигуры на целевую клетку — тоже ход.
- При обязательном взятии подсвечиваются только бьющие фигуры и их серии.

## Серии взятий
Ввод пошаговый: после первого прыжка подсвечиваются допустимые продолжения.
Движок не даст остановиться раньше времени, если бой можно продолжить
(правило «ешь, пока можешь»). Среди допустимых маршрутов выбор за вами.

## Нотация и вариации
- Клик по ходу в дереве переносит доску в позицию после него.
- Вариации отображаются ветвями с отступом; цвет линии показывает глубину.
- Комментарии `{…}` стоят рядом с ходом курсивом; клик по комментарию открывает
  редактор (изменить/удалить). Новая заметка — кнопкой комментария в панели
  управления (работает, когда выбран не стартовый узел).

## Расстановка позиции
Меню → «Расстановка позиции». Справа появляется паспорт тегов, под доской —
палитра и FEN‑плашка.

- Выберите фигуру в палитре и кликайте по **тёмным** клеткам (светлые
  заблокированы и заштрихованы).
- Простая белая на 8‑й горизонтали и простая чёрная на 1‑й автоматически
  ставятся дамками.
- Переключатель «Ход» задаёт очередь; FEN‑плашка и предпросмотр тегов справа
  обновляются в реальном времени.
- Иконка «картинка со стрелкой» (после «начальной расстановки») сохраняет
  текущую доску в **SVG** — удобно делиться позицией.
- «Применить» делает расстановку партией; «Отмена» возвращает прежнюю позицию
  и теги.

## Загрузка и сохранение PDN
- **Загрузить** → из файла или из буфера обмена. Принимает партии с тегами,
  вариациями, комментариями и `FEN`.
- **Сохранить** → в файл или в буфер. Перед сохранением открывается редактор
  тегов (Event/Site/White/Black/Date/Round/Result); имя файла собирается из
  имён игроков и даты.

## Темы и скины доски
В правом углу шапки — две иконки: палитра (тема интерфейса) и рамка‑доска
(скин доски и фигур). Выбор из семи вариантов в каждом списке сохраняется
между сеансами. Скин меняет форму и материал фигур и текстуру полей; тема —
цвета окружения.

## Горячие клавиши
| Клавиша | Действие |

| ← / → | назад / вперёд по ходам |
| Home / End | в начало / в конец |
| F | перевернуть доску |
| Esc | закрыть открытую модалку или пикер |
